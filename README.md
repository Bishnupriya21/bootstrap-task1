# Bootstrap 5 Internship Project - UI Design

## About The Project
This project is part of an internship task to practice Bootstrap 5 by designing three responsive web pages: Home, About, and Contact. The goal was to explore Bootstrap components, remix them creatively, and build visually appealing and mobile-friendly pages.

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5 (via CDN)
- Git & GitHub for version control and hosting

## How I Completed The Project
- Created three HTML files (`index.html`, `about.html`, `contact.html`) with consistent navbar and footer.
- Explored Bootstrap 5 official examples for UI components like navbar, hero, cards, and forms.
- Built the Home page with a navbar, hero section, feature cards, and footer.
- Designed About page with service cards and consistent layout.
- Developed Contact page with a bootstrap-styled form including validation.
- Hosted the project on GitHub Pages for live preview.

## Tools and Resources
- Bootstrap official documentation
- VS Code for code editing
- Git command line for version control
- GitHub for hosting the repository and live site
- ChatGPT for assistance with code snippets and clarifications

## Challenges Faced
- Understanding Bootstrap’s grid and utility classes initially took some time.
- Making sure all pages had consistent navigation and branding.
- Deploying on GitHub Pages for the first time was slightly confusing but manageable.

## Learning Outcomes
- Improved knowledge of Bootstrap 5 components and layout techniques.
- Hands-on experience with responsive web design.
- Gained familiarity with Git, GitHub, and GitHub Pages deployment.
- Developed ability to remix UI components and build original page layouts.

## Time Taken
Approximately 6-8 hours spread over several days for design, coding, debugging, and deployment.
